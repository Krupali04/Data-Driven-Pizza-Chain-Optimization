# Data-Driven Pizza Chain Optimization
This project focuses on optimizing business operations for a pizza chain by leveraging data analysis and visualization tools. The goal is to streamline data processing, uncover key performance insights, and provide actionable recommendations for business improvements.

### Technologies Used:
Excel: Data cleaning, pivot tables, VLOOKUP, and array formulas for aggregating and structuring raw data.
BigQuery: Data storage and SQL-based analysis for exploring customer behavior, sales trends, and supply chain efficiency.
Looker: Data visualization and dashboard creation to enable actionable insights for business decision-making.

### Key Features:
Data Cleaning and Aggregation: Utilized Excel techniques like pivot tables, VLOOKUP, and array formulas to clean and structure datasets from multiple operational sources, including sales, inventory, and customer data.

BigQuery Analysis: Loaded and explored data in BigQuery, writing optimized SQL queries to analyze customer purchasing behavior, inventory turnover, and supplier efficiency.

Looker Dashboards: Developed interactive dashboards featuring:
Performance Analysis: Insights into top-performing pizzas and categories, as well as identification of low-performing pizzas.
Time-Based Trends: Hourly and weekly sales trends to identify peak times and seasonal variations.
Category and Size Insights: Breakdown of sales across pizza categories and sizes, identifying high-revenue contributors.

Business Impact:
The dashboards and data analysis provided critical insights to enhance product offerings, optimize pricing, improve inventory management, and streamline supply chain processes, leading to increased operational efficiency and customer satisfaction.

### Installation:
To replicate or use the project, follow these steps:

Clone this repository.
Set up the necessary Google Cloud services (BigQuery and Looker) with your data.
Use Excel for initial data cleaning and aggregation.
Load the cleaned data into BigQuery and perform exploratory analysis using SQL.
Use Looker to build dashboards with custom dimensions and table calculations.
